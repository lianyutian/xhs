## MODIFIED Requirements

### Requirement: 受保护的写入操作须进行所有权和频率控制
系统 SHALL 对经过身份验证的写入操作（如地址修改、地址删除和文件上传）应用所有权检查和请求频率控制。

#### Scenario: 地址写入请求因缺少所有权而被拒绝
- **WHEN** 经过身份验证的客户端尝试修改或删除一个不属于该认证用户的地址资源
- **THEN** 系统将拒绝该请求，并将所有权失败记录为与安全相关的事件

#### Scenario: 地址不存在时保持最小披露语义
- **WHEN** 经过身份验证的客户端尝试修改或删除一个不存在的地址资源
- **THEN** 系统将返回与越权地址相同的客户端可见结果，并将该失败视为所有权相关拒绝处理

#### Scenario: 上传请求受文件和频率策略约束
- **WHEN** 经过身份验证的客户端上传文件
- **THEN** 系统将在接受上传前，强制执行文件类型或大小限制以及请求频率限制
